D'Linkup ("we", "us", "our") operates the SourceTruth API ("Service"). This Privacy Policy describes how we collect, use, store, and disclose information from and about you when you use the Service.

By using the Service, you consent to the data practices described in this Policy. If you do not agree, please do not use the Service.

2.3 What we do NOT collect

  • We do not store the raw API key — only its SHA-256 hash

3. How We Use Your Information

  • Service operation: Authenticate API keys, enforce rate limits and quotas, process billing
  • Communication: Send transactional emails (billing receipts, account notices, service changes) to the email on your API key record
  • Analytics: Understand usage patterns to improve the Service (aggregated, not sold to third parties)
  • Security and abuse prevention: Detect and prevent misuse, fraud, or violations of our Terms of Service
  • Legal compliance: Comply with applicable laws and respond to lawful requests from authorities

We do not sell your personal data to third parties. We do not use your query text to train AI models.

5. Data Retention

  • Query logs (api_usage table): 90 days, then deleted
  • Daily quota counts: 2 days rolling
  • API key records (api_keys table): Retained while the key is active. Deleted within 30 days of account termination on request.
  • Email addresses: Retained while the account is active. On request to delete, we remove the email from the api_keys record within 30 days. Note that Stripe may retain email data subject to its own retention policies.
  • Stripe billing data: Retained by Stripe per their data retention policy (typically 7 years for financial records).

6. Data Security

  • API keys are stored only as SHA-256 hashes — the raw key is never stored and cannot be recovered
  • All API traffic is encrypted in transit via TLS (Cloudflare-managed SSL)
  • Database connections use TLS in transit
  • We use Supabase Row Level Security (RLS) policies to restrict data access
  • Access to production databases is restricted to authorised personnel and service accounts

No system is perfectly secure. In the event of a data breach that affects your personal data, we will notify you and relevant regulators as required by applicable law.
