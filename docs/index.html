SourceTruth API

Semantic search and AI-powered Q&A over 30 pre-indexed canonical corpora — Quran, Bible, Plato, Confucius, and more. No ingestion pipeline. One API key.

Base URL: https://api.sourcetruth.io  ·  Version: 1.0.0

New here? Jump to Quick start to make your first call in under two minutes, or issue a free key now.

Quick start

1. Get a free API key

curl
curl -X POST https://api.sourcetruth.io/v1/keys \
  -H "Content-Type: application/json" \
  -d '{"name": "My App", "email": "you@example.com"}'

# → {"key": "st_a1b2c3...", "tier": "free", "daily_limit": 100}

Store the key — it is shown only once.

2. Search a corpus

Python
import requests

r = requests.post(
    "https://api.sourcetruth.io/v1/search",
    headers={"X-API-Key": "st_..."},
    json={
        "query": "What does the Quran say about patience?",
        "corpus_codes": ["quran", "sahih-bukhari"],
        "top_k": 5,
    },
)
for p in r.json()["passages"]:
    print(p["reference"], p["text"][:100])

3. Get a grounded answer (paid tiers)

Python
r = requests.post(
    "https://api.sourcetruth.io/v1/answer",
    headers={"X-API-Key": "st_..."},
    json={
        "question": "What does the Quran say about patience?",
        "corpus_codes": ["quran", "sahih-bukhari"],
    },
)
print(r.json()["answer"])   # grounded prose with numbered citations
print(r.json()["citations"]) # [{"index":1,"reference":"2:153","corpus":"quran",...}]

Authentication

Pass your API key in the X-API-Key request header. Keys are prefixed st_.

Header
X-API-Key: st_a1b2c3d4e5f6...

/v1/search and /v1/corpora accept anonymous requests (rate-limited). /v1/answer requires a paid key.

POST /v1/search

Hybrid semantic + keyword retrieval over indexed corpora. Returns ranked passages with citation metadata. Available to all tiers including free.

Request body

FieldTypeDescription
query requiredstringNatural language query in any supported language.
corpus_codes optionalstring[]Scope to specific corpora — e.g. ["quran","sahih-bukhari"]. Takes priority over traditions for reranking. See corpus codes.
traditions optionalstring[]Filter by tradition — e.g. ["islam"], ["theravada"].
languages optionalstring[]Filter by ISO language code — e.g. ["en"], ["ara"].
collections optionalstring[]Filter by collection within a corpus — e.g. ["MN","DN"] for SuttaCentral.
top_k optionalintegerPassages to return. Default 8, max 20.
Cross-corpus tip: For balanced results across two corpora (e.g. Quran + Hadith, Tanakh + Mishnah), make two scoped calls and merge. A single unscoped call may be dominated by whichever corpus has stronger semantic overlap.

Response

JSON
{
  "query": "What does the Quran say about patience?",
  "passages": [{
    "chunk_id": 18432,
    "text": "O you who have believed, seek help through...",
    "reference": "2:153",
    "tradition": "islam",
    "language": "en",
    "corpus": "quran",
    "score": 0.912
  }],
  "resolved_entities": [],
  "latency_ms": 84
}

POST /v1/answer

Retrieval-augmented generation. Retrieves relevant passages then generates a grounded answer via Claude with numbered inline citations. Requires Starter or Professional.

Request body

FieldTypeDescription
question requiredstringThe question to answer from the corpus.
corpus_codes optionalstring[]Scope retrieval to specific corpora.
traditions optionalstring[]Filter retrieval by tradition.
languages optionalstring[]Filter retrieval by language.
max_passages optionalintegerPassages to retrieve as context. Default 6, max 10.

Response

JSON
{
  "question": "What does the Quran say about patience?",
  "answer": "The Quran emphasises patience (sabr) repeatedly.
In 2:153 believers are instructed to seek help
through patience and prayer [1]...

Citations:
[1] 2:153 — Surah Al-Baqarah",
  "citations": [{ "index": 1, "reference": "2:153", "corpus": "quran" }],
  "latency_ms": 1840
}
The answer model (claude-sonnet-4-6) is instructed never to invent references from memory. If passages don't answer the question, it says so explicitly.

GET /v1/corpora

Returns all indexed corpora with codes, traditions, languages, and licence metadata. No authentication required. Use returned code values as corpus_codes filter values.

curl
curl https://api.sourcetruth.io/v1/corpora

GET /v1/text/{uid}

Returns the full chunked text of a document by its canonical external ID (e.g. sn56.11, mn10). UIDs are returned as sutta_id in search results.

ParamInDescription
uid requiredpathCanonical document ID.
lang optionalqueryLanguage code. Default en.

GET /v1/entity/{entity_id}

Returns entity metadata and name variants (Sanskrit, Chinese, Tibetan, English). Entity IDs appear in the resolved_entities array of search results when named entities are detected in the query.

POST /v1/keys

Self-issue a free-tier API key. No authentication required. Rate-limited to 5 per hour per IP.

FieldTypeDescription
name requiredstringYour name or application name.
email requiredstringValid email address.
JSON response
{ "key": "st_a1b2c3...", "tier": "free", "daily_limit": 100,
  "message": "Store this key safely — it will not be shown again." }

DELETE /v1/keys

Immediately revoke your API key. Pass the key in X-API-Key. Irreversible.

GET /health

Health check. No authentication required.

JSON
{ "status": "ok", "version": "1.0.0" }

Rate limits & tiers

Free100—$0
Starter1,000100$29/mo

Hard per-minute limits: 60 req/min on /v1/search, 20 req/min on /v1/answer. Exceeded limits return HTTP 429. Upgrade at sourcetruth.io/pricing.

Error codes

StatusMeaning

403Endpoint requires a paid plan.
404Resource not found.
429Daily quota or per-minute rate limit exceeded.
503Billing not configured.

const res = await fetch("https://api.sourcetruth.io/v1/search", {
